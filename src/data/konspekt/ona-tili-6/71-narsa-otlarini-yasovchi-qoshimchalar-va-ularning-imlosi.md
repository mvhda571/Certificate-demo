# 71-mavzu. Narsa otlarini yasovchi qo‘shimchalar va ularning imlosi

## Asosiy g‘oya
Narsa otlari **-gich, -gi, -k (-q), -oq, -(i)ndi, -ma, -don** qo‘shimchalari bilan yasaladi (supurgich, elak, chiqindi, guldon); **-q** a bilan tugagan fe’lga qo‘shilsa **a → o** (bo‘yoq, taroq). (Darslik: 124–125-betlar)

## Qoida
| Qo‘shimcha | Misollar |
|---|---|
| -gich (-qich, -kich, -g‘ich) | supurgich, qirg‘ich, kesgich |
| -gi (-qi, -ki, -g‘i) | supurgi, suzgi, chizg‘i |
| -k, -q | elak, qo‘shiq, bo‘yoq |
| -oq | qishloq, o‘ynoq |
| -(i)ndi | supurindi, qirindi, chiqindi |
| -ma | qovurma, suzma, tugma |
| -don | qalamdon, guldon, choydon |

## Imlo
**-q** qo‘shimchasi **a** bilan tugagan fe’lga qo‘shilsa, **a → o** talaffuz qilinadi va shunday yoziladi: bo‘ya + q = bo‘yoq, tara + q = taroq.

## Eslab qolish hiylasi
**Bo‘ya + q = bo‘yoq, tara + q = taroq.** Gul + don = guldon.

## Takrorlash uchun savollar
1. Narsa oti yasovchi qo‘shimchalar qaysilar?
2. bo‘yoq, taroq so‘zlarining yasalishini tushuntiring.
