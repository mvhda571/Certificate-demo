# 69-mavzu. Shaxs oti yasovchi qo‘shimchalar va ularning imlosi

## Asosiy g‘oya
Shaxs otlari **-chi, -soz, -kor, -xon, -dosh, -boz, -vchi, -lik** bilan yasaladi; **-vchi** i dan keyin **i → u** (o‘quvchi), a dan keyin **a → o** (tinglovchi); **-lik** atoqli otni turdoshga aylantiradi (samarqandlik). (Darslik: 121–122-betlar)

## Qoida
Shaxs otlari **-chi, -soz, -kor, -xon, -dosh, -boz (-voz), -vchi, -lik** qo‘shimchalari bilan yasaladi.

| Qo‘shimcha | Misol |
|---|---|
| -chi | ishchi, sportchi |
| -soz | soatsoz, mashinasoz |
| -kor | paxtakor, ijodkor |
| -xon | kitobxon, gazetxon |
| -dosh | sinfdosh, vatandosh |
| -boz (-voz) | dorboz, masxaraboz |
| -vchi / -uvchi | o‘quvchi, sotuvchi; quruvchi, suzuvchi |
| -lik | samarqandlik, shaharlik |

## Imlo qoidalari
- **-vchi** qo‘shimchasi **i** bilan tugagan fe’lga qo‘shilsa, **i → u**: o‘qi + vchi = o‘quvchi.
- **a** bilan tugagan fe’lga qo‘shilsa, **a → o**: tingla + vchi = tinglovchi, ishla + vchi = ishlovchi.
- **Undosh** bilan tugagan fe’llarga **-uvchi** shaklida qo‘shiladi: quruvchi, suzuvchi.

## Esda tuting
**-lik** o‘rin-joy bildiruvchi otlarga qo‘shilib, shaxsning **shu hududga mansubligini** bildiradi. Atoqli otga qo‘shilsa, uni **turdosh otga** aylantiradi va **kichik harf** bilan yoziladi: samarqandlik, buxorolik.

## Eslab qolish hiylasi
**O‘qi → o‘quvchi, tingla → tinglovchi, Samarqand → samarqandlik.**

## Takrorlash uchun savollar
1. Shaxs oti yasovchi qo‘shimchalar qaysilar?
2. -vchi qo‘shimchasi qo‘shilganda qanday o‘zgarish yuz beradi?
