# 68-mavzu. Shaxs otlari

## Asosiy g‘oya
**Shaxs otlari** kim? so‘rog‘iga javob beradi va shaxsni **yoshi, yashash joyi, mansabi, kasbi, ijtimoiy holati, qarindoshligi, nasl-nasabi**ga ko‘ra nomlaydi. (Darslik: 120–121-betlar)

## Qoida
Shaxs otlari **kim?** so‘rog‘iga javob bo‘lib, shaxslarni quyidagi belgilariga ko‘ra nomlaydi:

| Belgi | Misollar |
|---|---|
| yoshi | bola, chol, yigit, o‘smir |
| yashash joyi | shaharlik, qishloqi, toshkentlik |
| mansab-unvoni | rais, vazir, professor |
| kasb-kori | o‘qituvchi, shifokor, duradgor |
| ijtimoiy holati | talaba, nafaqaxo‘r |
| qarindoshlik darajasi | ota, ona, aka, tog‘a |
| nasl-nasabi | o‘zbek, qozoq |

## Eslab qolish hiylasi
**Bola (yosh), toshkentlik (joy), shifokor (kasb), ota (qarindosh).**

## Takrorlash uchun savollar
1. Shaxs otlari deb nimaga aytiladi?
2. -lik qo‘shimchasi bilan qanday shaxs otlari yasaladi?
