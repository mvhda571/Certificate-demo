# 80-mavzu. Sifat yasovchi qo‘shimchalar va ularning imlosi

## Asosiy g‘oya
Sifat yasovchi qo‘shimchalar: egalik — **-li, ser-, -dor, ba-, -mand**; ega emaslik — **-siz, no-, be-**; moyillik — **-chan**; xoslik — **-iy, -gi**; o‘xshashlik — **-simon**. (Darslik: 136–138-betlar)

## Asosiy qo‘shimchalar
| Qo‘shimcha | Ma’nosi | Misol |
|---|---|---|
| -li | belgiga egalik | aqlli, kuchli |
| ser- | belgiga egalik (ko‘plik) | sersuv, serhosil |
| -dor | belgiga egalik | obro‘dor, mevador |
| ba- | belgiga egalik | baquvvat, bama’ni |
| -mand | belgiga egalik | davlatmand, hunarmand |
| -siz | ega emaslik | kuchsiz, suvsiz |
| no- | ega emaslik | noma’lum, noqulay |
| be- | ega emaslik | bema’ni, beg‘ubor |
| -chan | moyillik | ishchan, kuychan |
| -ma | fe’ldan sifat | qaynatma, osma |
| -iy (-viy) | xoslik | ilmiy, tarixiy, kimyoviy |
| -gi (-ki, -qi) | payt va o‘ringa xoslik | kechki, bahorgi, tashqi |
| -simon | o‘xshashlik | odamsimon, tuxumsimon |

## Esda tuting
- **-li, -dor, ba-, ser-, -mand** — belgiga **egalik**ni bildiradi.
- Ular (-mand dan tashqari) **no-, -siz, be-** bilan **zid ma’noli**: kuchli — kuchsiz, serhosil — hosilsiz, ma’noli — bema’ni.

## Eslab qolish hiylasi
**Kuchli ↔ kuchsiz, serhosil ↔ hosilsiz, ma’noli ↔ bema’ni.**

## Takrorlash uchun savollar
1. Sifat yasovchi qo‘shimchalarni ayting.
2. Qaysi qo‘shimchalar zid ma’noli?
3. -simon, -gi, -iy qanday ma’no beradi?
