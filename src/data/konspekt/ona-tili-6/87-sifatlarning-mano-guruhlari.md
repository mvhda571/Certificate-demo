# 87-mavzu. Sifatlarning ma’no guruhlari

## Asosiy g‘oya
Sifatlar ma’nosiga ko‘ra **xususiyat, rang-tus, maza-ta’m, hajm-o‘lchov, hid, makon-zamon** sifatlariga bo‘linadi. (Darslik: 152–157-betlar)

## Qoida
| Guruh | Nimani bildiradi | Misollar |
|---|---|---|
| 1. Xususiyat sifatlari | narsaning turli xususiyat-holatlari | aqlli, mehribon, dangasa, quvnoq |
| 2. Rang-tus sifatlari | rang-tusi | oq, qizil, ko‘kimtir, havorang |
| 3. Maza-ta’m sifatlari | mazasi | shirin, achchiq, nordon, sho‘r |
| 4. Hajm-o‘lchov sifatlari | hajmi, vazni, o‘lchovi, shakli | katta, og‘ir, uzun, yumaloq |
| 5. Hid sifatlari | hidi | xushbo‘y, badbo‘y, qo‘lansa |
| 6. Makon-zamon sifatlari | o‘rin va vaqtga nisbatan belgi | qishki, kechki, tashqi, ichki, tog‘li |

## Eslab qolish hiylasi
**Rang — oq; ta’m — nordon; hid — xushbo‘y; zamon — qishki.**

## Takrorlash uchun savollar
1. Sifatlar qanday ma’no guruhlariga bo‘linadi?
2. Rang-tus sifatlari qaysilar?
3. Maza-ta’m sifatlariga qaysilar kiradi?
