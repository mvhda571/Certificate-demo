# 14-mavzu. So‘z tarkibida tartib

## Asosiy g‘oya
So‘z tarkibida qismlar qat’iy tartibda keladi: **asos + so‘z yasovchi + lug‘aviy shakl yasovchi + sintaktik shakl yasovchi**. (Darslik: 30–31-betlar)

## Qoida
So‘zning ma’noli qismlari ma’lum **tartibda** joylashadi:

**asos + so‘z yasovchi + lug‘aviy shakl yasovchi + sintaktik shakl yasovchi**

## Misollar
- ish + chi + lar + imiz (asos + so‘z yasovchi + ko‘plik + egalik)
- osh + paz + lar + ga; o‘qu + vchi + lar + ning; kitob + xon + lar + dan; ipak + chi + lik + dan.

## Eslab qolish hiylasi
**Ish + chi + lar + imiz:** asos → yasovchi → ko‘plik → egalik.

## Takrorlash uchun savollar
1. Asosga birinchi qaysi qo‘shimcha qo‘shiladi?
2. Sintaktik shakl yasovchi lug‘aviydan oldin kela oladimi? (Yo‘q.)
