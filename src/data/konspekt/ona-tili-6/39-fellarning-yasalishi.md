# 39-mavzu. Fe’llarning yasalishi

## Asosiy g‘oya
Fe’llar **-la, -a, -(a)y, -i, -sira, -sa, -(a)r, -illa, -ira, -lan, -lash** qo‘shimchalari bilan boshqa turkumlardan yasaladi (tuzla, o‘yna, qoray, sensira, yaltira). (Darslik: 74–76-betlar)

## Fe’l yasovchi qo‘shimchalar
| Qo‘shimcha | Qaysi so‘zdan | Misol |
|---|---|---|
| **-la** | ot, sifat, undov, taqlid, ravish | tuzla, yangila, dodla, tezla |
| **-a** | ot, sifat | sana, o‘yna, tuna |
| **-(a)y, -i** | ot, sifat (ba’zan ravish) | qoray, boyi, ko‘pay |
| **-sira, -sa** | ot, sifat; -sira **sen, siz** olmoshlaridan ham | suvsira, suvsa, sensira |
| **-(a)r** | sifat | oqar, qisqar |
| **-illa, -ira** | taqlid so‘zlar | chirqilla, yaltira, yiltira |
| **-lan, -lash** | ot, sifat | zavqlan, yaqinlash, suhbatlash |

## Eslab qolish hiylasi
**Taqlid + illa/ira: chirqilla, yaltira.** Sen + sira = sensira.

## Takrorlash uchun savollar
1. Taqlid so‘zlardan fe’l yasovchi qo‘shimchalarni ayting.
2. -sira qo‘shimchasi qaysi olmoshlardan fe’l yasaydi?
