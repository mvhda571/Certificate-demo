# 18-mavzu. Kesim. Fe’l kesim va ot kesim

## Asosiy g‘oya
**Kesim** — gapning markaziy bo‘lagi; **fe’l kesim** (sof fe’l) va **ot kesim** (fe’ldan boshqa turkumlar, harakat nomi) ga bo‘linadi. (Darslik: 37-dars, 52–53-betlar)

## Qoida
**Kesim** — gapning markaziy bo‘lagi; zamon, shaxs-son, mayl, tasdiq-inkor ma’nolarini ifodalaydi.
| Tur | Ifodalanishi | Ma’nosi |
|---|---|---|
| **Fe’l kesim** | sof fe’l, ba’zan ravishdosh (faqat **-guncha**li) | ish-harakat: Ishning boshi — boshlanguncha. |
| **Ot kesim** | fe’ldan boshqa turkumlar va harakat nomi | predmetning turi yoki belgisi |

## Ot kesimning ifodalanishi
| So‘z turkumi | Misol |
|---|---|
| Ot | Axloqi zamimalarning eng zararligi **hasaddur**. (A. Avloniy) |
| Sifat | Usti yaltiroq, ichi **qaltiroq**. |
| Son | Ikki o‘n besh — bir **o‘ttiz**. |
| Olmosh | O‘zim har joydaman, ko‘nglim **sandadur**. |
| Ravish | Savobning eshigi **ko‘p**. |
| Modal so‘z | So‘zdan so‘zning farqi **bor**. |
| Harakat nomi | Burchimiz — a’lo **o‘qish**. |
| Sifatdosh | Yigit kishining uyalgani — **o‘lgani**. |
| Taqlid so‘z | Ko‘chada odam **g‘ij-g‘ij**. |
| Undov | Endi uning holiga **voy**. |

## Eslab qolish hiylasi
**Ishla! — fe’l kesim; Hasaddur — ot kesim.**

## Takrorlash uchun savollar
1. Fe’l kesim va ot kesimning farqi nimada?
2. Ot kesim qaysi so‘z turkumlari bilan ifodalanadi?
