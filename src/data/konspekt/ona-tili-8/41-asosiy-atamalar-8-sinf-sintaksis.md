# 41-mavzu. Asosiy atamalar (8-sinf sintaksis)

## Asosiy g‘oya
8-sinf sintaksis atamalari: so‘z birikmasi, bitishuv, boshqaruv, moslashuv, gap turlari, kesim, ega, ikkinchi darajali bo‘laklar, uyushiq va ajratilgan bo‘laklar, kiritma, undalma. (Darslik: 100-dars, 138-bet)

## Umumiy ma’lumot
| Atama | Izohi |
|---|---|
| **Sintaksis** | so‘z birikmasi va gapni o‘rganuvchi bo‘lim |
| **So‘z birikmasi** | kamida ikki mustaqil so‘zning tobe bog‘lanishi |
| **Hokim / tobe so‘z** | birikmadagi izohlanuvchi / izohlovchi so‘z |
| **Bitishuv** | tobe so‘z hokim so‘zga qo‘shimchasiz, tartib va ohang bilan bog‘lanishi (yangi bino) |
| **Boshqaruv** | tobe so‘zning kelishik yoki ko‘makchi bilan bog‘lanishi (kitobni o‘qidi) |
| **Moslashuv** | tobe va hokim so‘zning shaxs-sonda moslashishi (mening kitobim) |
| **Sodda gap** | bitta shakllangan kesimli gap |
| **Darak / so‘roq / buyruq / istak gap** | ifoda maqsadiga ko‘ra gap turlari |
| **Kesim** | gapning markaziy, shakllangan bo‘lagi |
| **Ot kesim** | fe’ldan boshqa turkum bilan ifodalangan kesim |
| **Murakkab kesim** | birdan ortiq so‘zdan iborat kesim |
| **Bog‘lama** | ot kesimni ega bilan bog‘lovchi so‘z |
| **Ega** | harakat bajaruvchisi, belgi sohibi |
| **Atov gap** | narsa-hodisani nomlab, ko‘z oldiga keltiruvchi gap |
| **So‘z-gap** | kengayolmaydigan, bir so‘zdan iborat gap |
| **Yig‘iq / yoyiq gap** | faqat bosh bo‘lakli / ikkinchi darajali bo‘lakli gap |
| **Hol** | harakatning o‘rni, payti, holati, sababi, maqsadini bildiruvchi bo‘lak |
| **To‘ldiruvchi** | fe’lga boshqaruv yo‘li bilan bog‘langan bo‘lak |
| **Aniqlovchi / aniqlanmish** | ot bilan ifodalangan bo‘lakni aniqlovchi / aniqlangan bo‘lak |
| **Mantiqiy urg‘u** | ta’kidlangan bo‘lakning kuchli ohang bilan aytilishi |
| **Uyushiq bo‘lak** | bir bo‘lakka tobelangan teng bo‘laklar |
| **Ajratilgan bo‘lak** | mazmun va ohang jihatdan ajratilgan izoh bo‘lak |
| **Kiritma** | gap bo‘laklari bilan aloqaga kirishmaydigan qo‘shimcha axborot |
| **Undalma** | nutq qaratilgan shaxs yoki narsa |

## Eslab qolish hiylasi
**Bitishuv — qo‘shimchasiz; boshqaruv — kelishik bilan; moslashuv — shaxs-sonda.**
