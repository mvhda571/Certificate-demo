# 9-mavzu. Nazariy ma’lumot: She’riy san’atlardan namunalar

## Asosiy g‘oya
Mumtoz she’riyatning asosiy san’atlari: **tashbeh, istiora, tazod, talmeh, tajohil ul-orif, husni ta’lil, tajnis, ta’did, tanosib, tasdir, tasbe, tardi aks, nido**. (Darslik: 167–181-betlar)

## Umumiy ma’lumot
| San’at | Mohiyati | Misol |
|---|---|---|
| **Tashbeh** (o‘xshatish) | ikki narsa o‘rtasidagi o‘xshashlikni qiyoslash; qismlari: mushabbah (o‘xshatilgan), mushabbahbih (o‘xshagan), vajhi shabah (sabab), holati tashbeh (vosita) | «Ul sanamkim, suv yaqosinda paritek o‘lturur» (Atoyi) |
| **Istiora** («qarz olish») | o‘xshatish vositasi va sababi tushirilgan, **qisqartirilgan o‘xshatish** | «la’l» — lab/so‘z; «sarvi ozod» — qomat; Navoiyda «oy», «muhabbat tuxmi», «o‘t» |
| **Tazod** | zid qo‘yish | «Manga sensiz tirilgandin o‘lim yuz qatla ortuqdur»; «Mengizlari gul-gul, mijalari xor, Qaboqlari keng-keng, og‘izlari tor» |
| **Talmeh** («bir nazar tashlash») | tarixiy-afsonaviy voqea, shaxsga ishora | «Sulaymon saltanatlik podshosen, Masih anfoslik, Yusufliqosen» (Xorazmiy) |
| **Tajohil ul-orif** | bilib bilmaslikka olish | «Mengiz yo ravzai rizvonmudur bu?» (Atoyi) |
| **Husni ta’lil** | hodisaga shoirona (real bo‘lmagan) sabab topish | «Quyosh oydek yuzungning xijlatidin Qochib, to‘rtinchi ko‘k uzra chiqibdur» (Lutfiy) |
| **Tajnis** (jinos) | shakldosh so‘zlarni turli ma’noda qo‘llash; tuyuq janriga asos | «Bo‘yung sarv-u sanubartek, beling qil, Vafo qilg‘on kishilarga vafo qil» (Xorazmiy) |
| **Ta’did** | narsa-hodisalarni sanab ketish | «Dardga to‘lding, g‘amga to‘lding, telba bo‘lding» (Yassaviy) |
| **Tanosib** | ma’noviy bog‘liq so‘zlarni birga qo‘llash | «Olma yanoqing... Bodom ko‘zi fitna, pista dahani nozuk» (Lutfiy) |
| **Tasdir** | bayt boshidagi so‘z oxirida takrorlanadi | «Men bu yuz mushtoqidurmen... arg‘uvon sizsiz menga» (Atoyi) |
| **Tasbe** | misra oxiridagi so‘z keyingi misra boshida takrorlanadi | «Kuchum yetguncha ko‘p qildim vafolar, Vafoli qulni asrar podsholar» (Xorazmiy) |
| **Tardi aks** | takrorlangan so‘zlar o‘rni almashadi | «Ko‘zung ne balo qaro bo‘lubtur, Kim, jong‘a qaro balo bo‘lubtur» (Navoiy) |
| **Nido** | his-hayajon bilan murojaat | «Ey sabo, holim borib sarvi xiromonimg‘a ayt» (Navoiy) |

- So‘z takroriga asoslangan san’atlar: **ishtiqoq, tasdir, tasbe, takrir, aks, tardi aks, rad**.

## Eslab qolish hiylasi
**Tashbeh — to‘liq o‘xshatish, istiora — qisqartirilgan o‘xshatish.** Tasdir — boshi oxirida, tasbe — oxiri boshida.

## Takrorlash uchun savollar
1. Tashbeh va istiora o‘rtasidagi farq nimada?
2. Husni ta’lilga misol keltiring.
3. Tasdir, tasbe va tardi aksni farqlang.
