# 14-mavzu. Nazariy ma’lumot: Ramziy obrazlar

## Asosiy g‘oya
Adabiyotda **ramz** — tasavvur qilish qiyin hodisa yoki tushunchani ko‘z oldiga yaqqol keltiradigan narsa orqali ifodalash. Ko‘chma ma’noga ega timsollar — **ramziy obrazlar**. (Darslik: 129–131-betlar)

## Ta’rif
**Ramz** (grekcha **«symbolon»**) — qadimgi greklarda **maxfiy tashkilot** a’zolari bir-birini tanish uchun ishlatgan **shartli belgi**.

## Misollar
| Ramz | Ma’nosi |
| --- | --- |
| Tulki | ayyorlik |
| Burgut | mag‘rurlik, erk |
| Arslon | kuch, jasorat |
| Bulbul | oshiq |
| **Shoxdor ona bug‘u** («Oq kema») | ezgulik, mehr-oqibat, xalq |
| **Baliq** | erk va qudrat (bola nazarida) |
| **Oq kema** | to‘kislik, diydor, mehr-oqibat |

## Eslab qolish hiylasi
**Ramz = symbolon = shartli belgi.** «Oq kema»dagi uch ramz: **bug‘u — ezgulik, baliq — erk, kema — diydor**.

## Takrorlash uchun savollar
1. Ramz so‘zining kelib chiqishi qanday?
2. «Oq kema»dagi ramziy obrazlarni sharhlang.
