# 42-mavzu. Rasmiy uslub (tushuntirish xati, ariza, ma’lumotnoma, bayonnoma, tilxat)

## Asosiy g‘oya
**Rasmiy uslub** — yozma rasmiy shakl bo‘lib, qat’iy **nutqiy qoliplar**ga ega. Ish yuritish hujjatlari **tashkiliy, farmoyish, ma’lumot-axborot** va **xizmat yozishmalari** guruhlariga bo‘linadi. (Darslik: 62–63-darslar, 98–102-betlar)

## Qoida
Adabiy tilning **yozma rasmiy** shakliga xos bo‘lib, muayyan **nutqiy qolip**, qat’iy odat tusiga kirib qolgan shakllarga ega bo‘lgan nutq uslubi **rasmiy uslub** sanaladi.

- Qo‘llanish doirasi: davlatlararo diplomatik munosabatlar, idora va korxonalarning rasmiy ish yuritishi, ariza, tilxat, ishonch qog‘ozi kabi hujjatlar.

## Ish yuritish hujjatlari guruhlari
| Guruh | Hujjatlar |
|---|---|
| 1. Tashkiliy | guvohnoma, yo‘riqnoma, nizom, shartnoma |
| 2. Farmoyish | buyruq, ko‘rsatma, farmoyish |
| 3. Ma’lumot-axborot | ariza, bayonnoma, dalolatnoma, ishonchnoma, tavsifnoma, tarjimayi hol, tilxat, tushuntirish xati, e’lon |
| 4. Xizmat yozishmalari | taklifnoma, telegramma, xatlar |

## Nutqiy qoliplar
- «Sizga ...ni **ma’lum qilaman(miz)** / bildiraman(miz) / eslataman(miz)».
- «...ga **rozilik bildiradi** / kafolat beradi / qarshi emas».
- Farmoyish hujjatlarida kesim: tayinlansin, topshirilsin (majhul nisbat, III shaxs, buyruq mayli).

## Hujjat namunalari tuzilishi
- **Ariza:** kimga (yuqori o‘ng tomonda) → kimdan → «ARIZA» → iltimos mazmuni (...so‘rayman) → sana, imzo.
- **Tushuntirish xati:** kimga, kimdan → «TUSHUNTIRISH XATI» → sabab bayoni → ilova (bo‘lsa) → imzo, sana.
- **Ma’lumotnoma:** raqam, sana → «MA’LUMOTNOMA» → tasdiqlanayotgan fakt → «...so‘ralgan joyga ko‘rsatish uchun berildi» → mas’ul shaxs imzosi.
- **Bayonnoma:** yig‘ilish nomi, sana, joy → qatnashdilar → kun tartibi → eshitildi → so‘zga chiqdilar → qaror qiladi → rais va kotib imzosi.
- **Tilxat:** Men, ... (kim) → kimdan, nimani, qanday shart bilan olgani → sana, imzo.

## Eslab qolish hiylasi
**4 guruh: Tashkiliy (nizom), Farmoyish (buyruq), Ma’lumot-axborot (ariza, tilxat), Xizmat yozishmasi (taklifnoma).**

## Takrorlash uchun savollar
1. Qanday uslubga rasmiy uslub deyiladi?
2. Rasmiy uslubning o‘ziga xos xususiyatlari nimalardan iborat?
3. Ish yuritish hujjatlari qanday turlarga bo‘linadi?
