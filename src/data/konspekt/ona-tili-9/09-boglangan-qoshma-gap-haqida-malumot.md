# 9-mavzu. Bog‘langan qo‘shma gap haqida ma’lumot

## Asosiy g‘oya
**Bog‘langan qo‘shma gap** qismlari teng bog‘lovchilar, **bo‘lsa, esa**, **-u (-yu), -da** yordamida bog‘lanadi va grammatik jihatdan **teng huquqli** bo‘ladi. (Darslik: 11-dars, 22–23-betlar)

## Qoida
Qismlari **teng bog‘lovchilar**, **bo‘lsa, esa** so‘zlari, **-u (-yu), -da** yuklamalari yordamida bog‘langan gaplar **bog‘langan qo‘shma gaplar** hisoblanadi.

- Qismlari grammatik jihatdan **teng huquqli** — biri ikkinchisiga tobe emas.
- Tahlilda qolipi: ikki to‘rtburchak orasida teng bog‘lovchi ko‘rsatiladi: [ ] **va** [ ].

## Bog‘lovchi vositasiga ko‘ra turlari
1. Biriktiruv bog‘lovchili (12-dars)
2. Zidlov bog‘lovchili (13-dars)
3. Ayiruv bog‘lovchili (14-dars)
4. Inkor bog‘lovchili (15-dars)
5. Bo‘lsa, esa yordamida (16-dars)

## Eslab qolish hiylasi
**Bog‘langan = teng huquqli: [ ] va [ ].** Besh turi: biriktiruv, zidlov, ayiruv, inkor, bo‘lsa/esa.

## Takrorlash uchun savollar
1. Bog‘langan qo‘shma gap deb qanday gaplarga aytiladi?
2. Bog‘langan qo‘shma gap qismlari qanday vositalar bilan bog‘lanadi?
