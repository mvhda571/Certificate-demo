# 61-mavzu. Iboralar

## Asosiy g‘oya
Ma’nosi **bir so‘zga teng** keladigan so‘zlar birikmasi — **ibora** (frazeologizm): dimog‘i chog‘ — xursand, kapalagi uchdi — qo‘rqdi. Iboralar nutqni ta’sirchan qiladi. (Darslik: 145–146-betlar)

## Ta’rif
- Ma’nosi **bir so‘zga teng** keladigan so‘zlar birikmasi yoki gaplar – **ibora** (frazeologizm).
- Misollar: dimog‘i chog‘ bo‘ldi (xursand), yuzini yerga qaratmoq (uyaltirmoq), qo‘li baland kelmoq (g‘olib chiqmoq).
- Iboralar nutqni **ta’sirchan, jozibali** qiladi.

## Iboralar va ma’nolari
| Ibora | Ma’nosi |
|---|---|
| adabini yemoq | qilmishiga yarasha jazo olmoq |
| burni ko‘tarilmoq | kibrlanmoq, gerdaymoq |
| misi chiqmoq | siri fosh bo‘lmoq |
| bu qulog‘idan kirib, u qulog‘idan chiqmoq | e’tibor bermaslik |
| yuzi shuvut bo‘lmoq | uyatli holda qolmoq |
| bir yoqadan bosh chiqarmoq | hamjihat bo‘lmoq |
| tilidan bol tommoq ↔ tilidan zahar tommoq | shirinso‘z ↔ zahar tilli |
| kapalagi uchmoq | qo‘rqmoq |
| og‘zi qulog‘ida | juda xursand |
| qo‘y og‘zidan cho‘p olmagan | juda yuvosh |

- “Og‘ayni chalish” iborasi “og‘a-ini – bir juft kalish” maqolidan qisqargan (E. Vohidov).

## Eslab qolish hiylasi
**Ibora = bitta so‘z ma’nosi:** misi chiqdi = fosh bo‘ldi.
