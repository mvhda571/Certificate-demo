# 78-mavzu. Ish qog‘ozlari ustida ishlash. Tabriknoma

## Asosiy g‘oya
**Tabriknoma** — bayram, yutuq, tug‘ilgan kun munosabati bilan yoziladigan **tabrik xati**: murojaat → tabrik sababi → tilaklar → imzo. (Darslik: 185–186-betlar)

## Ta’rif
- **Tabriknoma** (arab.-fors.) – **tabrik yozilgan xat**; bayram, yutuq, tug‘ilgan kun munosabati bilan yoziladi.

## Tuzilishi
1. Murojaat: Hurmatli do‘stim Javohir!
2. Tabrik sababi: Sizni ... tanlovidagi yutuqlaringiz bilan tabriklayman.
3. Tilaklar.
4. Imzo: Sizga hurmat bilan sinfdoshingiz Ulug‘bek.

## Tavsiya etiladigan so‘zlar
- qadrli, qutlayman, muborakbod etaman, ezgu (samimiy) tilaklar, sihat-salomatlik, orzularingiz ro‘yobga chiqsin.

## Eslab qolish hiylasi
**Tabriknoma = murojaat + sabab + tilak + imzo.**

## Takrorlash uchun savollar
1. Tabriknoma qanday tuziladi?
2. Tabriknomada qanday so‘zlar ishlatiladi?
