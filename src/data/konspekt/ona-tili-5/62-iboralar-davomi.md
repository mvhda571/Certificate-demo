# 62-mavzu. Iboralar (davomi)

## Asosiy g‘oya
Iboralarni bir so‘z bilan almashtirish mumkin: ko‘zini bo‘yamoq — aldamoq, laqqa tushmoq — aldanmoq. «Ko‘z» so‘zi bilan ko‘plab iboralar yasalgan. (Darslik: 146–147-betlar)

## Ibora va uning so‘z bilan ifodasi
| Ibora | So‘z |
|---|---|
| ko‘zini bo‘yamoq | aldamoq |
| laqqa tushmoq | aldanmoq |
| og‘zidan bol tomadigan | shirinsuxan |
| chehrasi ochilgan | xursand |
| o‘takasi yorilmoq | qo‘rqmoq |
| boshiga ko‘tarmoq | shovqin qilmoq / e’zozlamoq |
| yeng uchida ish qilmoq | yuzaki ishlamoq |
| oyog‘ini qo‘liga olib yugurmoq | shoshilmoq |

## “Ko‘z” so‘zi bilan iboralar
- ko‘zdan kechirmoq (tekshirmoq), ko‘zi ola-kula bo‘lmoq (qo‘rqmoq), ko‘zining qirini tashlamoq (yashirin qaramoq), ko‘zi to‘rt bo‘lib kutmoq (intizorlik bilan kutmoq), qosh qo‘yaman deb ko‘z chiqarmoq (yaxshilik qilaman deb ziyon yetkazmoq).

## Maqolga yaqin iboralar
- Qush uyasida ko‘rganini qiladi; sichqonning ini ming tanga; sen bog‘dan kelsang, u tog‘dan keladi.

## Eslab qolish hiylasi
**Ko‘zi to‘rt bo‘ldi — intizor kutdi; qosh qo‘yaman deb ko‘z chiqardi — yaxshilik o‘rniga ziyon.**

## Takrorlash uchun savollar
1. Iboralar nutqqa qanday ta’sir qiladi?
2. “Ko‘z” so‘zi bilan 3 ta ibora ayting.
