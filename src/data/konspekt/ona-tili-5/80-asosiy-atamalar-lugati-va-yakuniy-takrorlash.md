# 80-mavzu. Asosiy atamalar lug‘ati va yakuniy takrorlash

## Asosiy g‘oya
5-sinf ona tili kursining **asosiy atamalari** (fonetika, grafika, leksikologiya, morfologiya, sintaksis, punktuatsiya va boshqalar) va yil davomida o‘tilgan mavzular **umumlashtiriladi**. (Darslik: 188-bet)

## Umumiy ma’lumot
| Atama | Ta’rif |
|---|---|
| Antonimlar | qarama-qarshi ma’noli so‘zlar |
| Fonetika | nutqning tovush tizimini o‘rganuvchi bo‘lim |
| Grafika | yozma nutqning harflar tizimini o‘rganuvchi bo‘lim |
| Ibora | ma’nosi bir so‘zga teng keladigan ko‘chma ma’nodagi so‘zlar qo‘shilmasi |
| Leksikografiya | lug‘at va uning turlarini o‘rganuvchi bo‘lim |
| Leksikologiya | so‘z va uning xususiyatlarini o‘rganuvchi bo‘lim |
| Morfologiya | so‘z turkumlarini o‘rganuvchi bo‘lim |
| Omonimlar | yozilishi va aytilishi bir xil, ma’nosi turlicha so‘zlar |
| Orfografiya | so‘zlarning to‘g‘ri yozilishini o‘rgatuvchi bo‘lim |
| Paronim | aytilishi va yozilishi bir-biriga yaqin so‘zlar |
| Punktuatsiya | tinish belgilari haqidagi bo‘lim |
| Sinonimlar | shakli har xil, ma’nosi yaqin so‘zlar |
| Sintaksis | gap va gapda so‘zlarning bog‘lanishini o‘rganuvchi bo‘lim |

## Yil oxiridagi takrorlash (132–136-darslar)
- **Fonetika va grafika:** unli (6) va undosh (24) tovushlar, nutq a’zolari, tovush ortishi/tushishi/almashishi, bo‘g‘in, urg‘u, alifbo (26 harf + 3 birikma + tutuq belgisi).
- **Imlo:** unlilar va undoshlar imlosi, qo‘sh va qator undoshlar, qo‘shib/ajratib/chiziqcha bilan yozish, bosh harflar, ko‘chirish.
- **Leksikologiya:** sinonim, omonim, antonim, paronim; o‘z va o‘zlashma qatlam; yangi, tarixiy, arxaik so‘zlar; terminlar; iboralar, maqollar, hikmatli so‘zlar.
- **Lug‘atshunoslik:** imlo, izohli, tarjima, ensiklopedik lug‘atlar.

## Eslab qolish hiylasi
**Tovush — fonetika, harf — grafika, so‘z — leksikologiya, gap — sintaksis, belgi — punktuatsiya.**
