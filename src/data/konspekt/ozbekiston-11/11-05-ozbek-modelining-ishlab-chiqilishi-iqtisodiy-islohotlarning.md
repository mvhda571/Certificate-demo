# 11-sinf, 5-mavzu. O‘zbek modelining ishlab chiqilishi. Iqtisodiy islohotlarning boshlanishi

## Asosiy g‘oya
O‘zbekiston bozor iqtisodiyotiga o‘tishda **"o‘zbek modeli"**ni tanladi — **5 tamoyil**: iqtisodning siyosatdan ustunligi; davlat — bosh islohotchi; qonun ustuvorligi; kuchli ijtimoiy siyosat; islohotlarni bosqichma-bosqich o‘tkazish. **1991-yil 18-noyabr** — xususiylashtirish qonuni. **1993-yil 15-noyabr** — **so‘m-kupon**, **1994-yil 1-iyul** — milliy valyuta **so‘m**.

## Tushuntirish
**O‘zbek modeli — 5 tamoyil:**
1. **Iqtisodiyotning siyosatdan ustunligi** (mafkurasizlantirish).
2. **Davlat — bosh islohotchi**.
3. **Qonun ustuvorligi**.
4. **Kuchli ijtimoiy siyosat**.
5. **Bosqichma-bosqich** (evolyutsion) o‘tish ("shok terapiya"siz).

**Xususiylashtirish:** **1991-yil 18-noyabr** — **"Mulkni davlat tasarrufidan chiqarish va xususiylashtirish to‘g‘risida"**gi qonun. **Kichik xususiylashtirish** (savdo, maishiy xizmat, uy-joy) — **1994**-yilgacha tugallandi; **1995** — ommaviy xususiylashtirish; **1994** — Davlat mulkini boshqarish qo‘mitasi.

**Milliy valyuta:** **1991–1993** — O‘zbekiston **rubl zonasida** edi. **1993-yil 15-noyabr** — **so‘m-kupon** muomalaga kiritildi (darslikda 1-noyabr), **1994-yil 1-iyul** — **milliy valyuta — so‘m**.

**Iqtisodiy mustaqillik:** **yoqilg‘i mustaqilligi** (Ko‘kdumaloq neft koni, **Buxoro neftni qayta ishlash zavodi** — 1997), **don mustaqilligi** (paxta maydoni qisqartirilib, bug‘doy ekildi).

**Transport:** **1994–2001** — **Navoiy–Uchquduq–Sultonuvaystog‘–Nukus** temiryo‘li (~**700 km**) — mamlakatning yagona temiryo‘l tarmog‘i; **G‘uzor–Boysun–Qumqo‘rg‘on** (2007), **Angren–Pop** (2016, **Qamchiq** tunneli).

## Eslab qolish hiylasi
**"5 tamoyil = 5 barmoq: Iqtisod, Davlat, Qonun, Ijtimoiy, Bosqich"**. **"1-iyul 1994 — So‘m tug‘ilgan kun"**.
