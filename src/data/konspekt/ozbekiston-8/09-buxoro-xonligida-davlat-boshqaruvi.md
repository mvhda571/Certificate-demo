# 9-mavzu. Buxoro xonligida davlat boshqaruvi

## Asosiy g‘oya
Oliy hukmdor — **xon**. Markaziy boshqaruvda **otaliq, devonbegi, qushbegi, parvonachi, ko‘kaldosh, qozikalon, shayxulislom** kabi mansablar bo‘lgan. Xonlik **viloyat → tuman → amlok** ga bo‘lingan.

## Tushuntirish
**Taxt vorisligi.** Shayboniylarda taxtni sulolaning **eng yoshi katta** vakili egallagan (Ko‘chkunchixon — Shayboniyxonning amakisi). Ikkinchi yoshi katta — **valiahd**. XVI asr 40-yillaridan bu an’ana buzilib, taxt **otadan o‘g‘ilga** o‘tadigan bo‘ldi.

**Markaziy mansablar:**
- **Otaliq** — xondan keyingi eng yuqori mansab (shahzoda murabbiysi, keyin amirlar amiri).
- **Devonbegi** — moliya va devon ishlari.
- **Parvonachi** — xon farmonlarini yetkazuvchi.
- **Ko‘kaldosh** — xonning yaqin maslahatchisi.
- **Qozikalon** — bosh qozi, sud ishlari.
- **Shayxulislom** — diniy ishlar boshlig‘i.
- **Qushbegi** — xon qarorgohi va poytaxt boshlig‘i (keyin bosh vazir).

**Mahalliy boshqaruv:** **viloyatlar** — sulola vakillaridan tayinlangan hokimlar; **tumanlar** — tuman hokimlari; eng quyi bo‘g‘in — **amlok** (bir necha qishloq). Amlokni **amlokdor** boshqargan, yordamchilari: **mirzo** (kotib), **mirob** (suv taqsimlovchi), **amin** (soliq yig‘uvchi), **oqsoqol** (qishloq boshlig‘i).

**Ashtarxoniylar davrida:** otaliq devonbegi darajasiga tenglashdi, keyin amirlar amiriga aylandi. **Saroy qutvoli** (qurilish, ta’mirlash) lavozimi joriy etildi. Devonlar tizimi deyarli barbod bo‘lib, hokimiyat saroyda to‘plandi.

## Atamalar
| Mansab | Vazifasi |
| --- | --- |
| Otaliq | Xondan keyingi oliy mansab |
| Qozikalon | Bosh qozi |
| Amlokdor | Amlok boshlig‘i |
| Mirob | Suv taqsimlovchi |
| Amin | Soliq yig‘uvchi |

## Eslab qolish hiylasi
Boshqaruv zinapoyasi: **"Viloyat → Tuman → Amlok → Qishloq"** — kattadan kichikka. **"Mirob — suv, Amin — soliq"**.

## Tez tekshiruv
1. Xonlikdagi eng quyi boshqaruv birligi? — Amlok.
2. Bosh qozi qanday atalgan? — Qozikalon.
3. Shayboniylarda taxtga kim chiqqan? — Sulolaning eng yoshi katta vakili.
