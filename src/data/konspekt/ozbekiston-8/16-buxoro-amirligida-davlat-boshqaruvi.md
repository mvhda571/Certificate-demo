# 16-mavzu. Buxoro amirligida davlat boshqaruvi

## Asosiy g‘oya
Amirlikda oliy hukmdor — **amir**. Oliy ijroiya hokimiyat — **qo‘shbegi** (bosh vazir) qo‘lida. Keyingi o‘rinda — **devonbegi** (moliya vaziri). Amirlik **bekliklarga** bo‘lingan, ularni **beklar** boshqargan.

## Tushuntirish
**Amir** — cheklanmagan hokimiyat egasi, qonun chiqaruvchi, oliy sudya, bosh qo‘mondon.

**Markaziy boshqaruv:**
- **Qo‘shbegi** (vaziri buzruk — bosh vazir) — poytaxt Buxorodagi ahvol, mamlakat boshqaruvi, moliya, soliq, xazinani nazorat qilgan. Barcha viloyatlar unga bo‘ysungan.
- **Devonbegi** (moliya vaziri, "quyi qo‘shbegi") — zakot masalalari.
- **Otaliq** — ilgari juda katta mavqega ega edi, endi faxriy unvonga aylandi.
- **Parvonachi** — muhim topshiriqlar (masalan, 1842-yilda Qo‘qonga **Ibrohim parvonachi** noib etib tayinlangan).
- **Qozikalon** (bosh qozi), **rais** (shariat qonunlari va axloqni nazorat qiluvchi), **mirshab** (tungi qorovul, politsiya), **mirzaboshi**, **zakotchi**.

Boshqaruv tizimi **devonxona, qozilik, mirshablik va harbiy idoralar**dan iborat bo‘lgan.

**Mahalliy boshqaruv:** amirlik **bekliklar**ga (viloyatlar) bo‘lingan (XIX asr o‘rtasida 20 dan ortiq). Bekni amir tayinlagan. Bekliklar **amloklar**ga, amloklar qishloqlarga bo‘lingan. Qishloqni **oqsoqol** boshqargan.

## Atamalar
| Mansab | Vazifasi |
| --- | --- |
| Qo‘shbegi | Bosh vazir |
| Devonbegi | Moliya vaziri |
| Rais | Shariat va axloq nazoratchisi |
| Mirshab | Tungi politsiya boshlig‘i |
| Bek | Viloyat (beklik) hokimi |

## Eslab qolish hiylasi
Xonlikda **Otaliq** birinchi edi, amirlikda **Qo‘shbegi** birinchi bo‘ldi ("O → Q"). **"Mirshab — Mir + shab (tun)"**.

## Tez tekshiruv
1. Buxoro amirligida bosh vazir kim? — Qo‘shbegi.
2. Moliya vaziri? — Devonbegi.
3. Amirlikning viloyatlari nima deb atalgan? — Bekliklar.
