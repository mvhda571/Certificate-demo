# 26-mavzu. Ko‘makchilarning ma’no turlari va qo‘shimchalar bilan ma’nodoshligi

## Asosiy g‘oya
Ko‘makchilar **sabab, maqsad, yo‘nalish, mavzu, o‘xshatish, chegara, birgalik** ma’nolarini bildiradi; ayrimlari qo‘shimchalar bilan ma’nodosh (tog‘dek — tog‘ kabi) va ma’lum kelishikni talab qiladi. (Darslik: 80–84-betlar)

## Ma’no turlari
| Ma’no | Ko‘makchilar |
|---|---|
| Sabab | sababli, tufayli, uchun |
| Maqsad | uchun |
| Yo‘nalish | tomon, qarab, sari, bo‘ylab |
| Mavzu | haqida, to‘g‘risida |
| O‘xshatish, qiyoslash | kabi, singari, yanglig‘ |
| Chegara | qadar |
| Birgalik, vosita | bilan, orqali |

## Ko‘makchi va qo‘shimcha ma’nodoshligi
- **-dek** = kabi, singari, yanglig‘ (o‘xshatish): tog‘dek — tog‘ kabi.
- Jo‘nalish kelishigi (-ga) = tomon, bo‘ylab (yo‘nalish): maktabga — maktab tomon.

## Ko‘makchilar bilan birga kelgan so‘zlarning shakli
| Kelishik | Ko‘makchilar |
|---|---|
| Bosh kelishik | bilan, kabi, singari, uchun, sari, sayin, bo‘ylab |
| Jo‘nalish kelishigi | ko‘ra, qaramay, yarasha, asosan, doir, muvofiq |
| Bosh va jo‘nalish | tomon |
| Chiqish kelishigi | keyin, bo‘lak, boshqa, o‘zga, tashqari, buyon, oldin, boshlab, avval |
| Qaratqich (ba’zan qo‘shimchasiz) | old, ost, ust (vazifadosh) |

## Eslab qolish hiylasi
**Haqida — mavzu, tufayli — sabab, kabi — o‘xshatish; ko‘ra — jo‘nalishdan keyin.**

## Takrorlash uchun savollar
1. Ko‘makchilar qanday ma’nolarni ifodalaydi?
2. Qaysi ko‘makchilar chiqish kelishigidagi so‘zga qo‘shiladi?
