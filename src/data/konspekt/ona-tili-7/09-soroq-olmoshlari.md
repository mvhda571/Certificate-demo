# 9-mavzu. So‘roq olmoshlari

## Asosiy g‘oya
Shaxs, narsa, belgi, miqdor, sabab, o‘rin, payt haqida **so‘roq** bildiruvchi olmoshlar — **so‘roq olmoshlari** (kim? nima? qanday? qancha? nega? qayer? qachon?). (Darslik: 28–30-betlar)

## Qoida
Shaxs, narsa-hodisa, belgi-xususiyat, miqdor, sabab, maqsad, o‘rin, payt haqida **so‘roqni** bildiruvchi olmoshlar — **so‘roq olmoshlari**.
| So‘roq | Nimani so‘raydi |
|---|---|
| kim? | shaxs |
| nima? | narsa |
| qanday? qanaqa? qaysi? | belgi |
| qancha? necha? | miqdor |
| nega? nima uchun? | sabab, maqsad |
| qayer? qayerda? | o‘rin |
| qachon? | payt |

- So‘roq olmoshli gaplar **so‘roq gap**; so‘roq ohangida aytiladi, oxiriga **so‘roq belgisi** qo‘yiladi: Siz qaysi kitoblarni o‘qigansiz?

## Eslab qolish hiylasi
**Kim — shaxs, nima — narsa, qachon — payt, nega — sabab.**

## Takrorlash uchun savollar
1. So‘roq olmoshlari nimalarni so‘raydi?
2. So‘roq olmoshli gap oxirida qanday tinish belgisi qo‘yiladi?
